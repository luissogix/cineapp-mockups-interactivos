# CineApp - Prototipo Interactivo (Metodología de Desarrollo)

Prototipo de alta fidelidad interactivo desarrollado para la asignatura de **Metodología**. Presenta el flujo transaccional de punto de venta y autoservicio para venta de entradas de cine, control de aforos, validación de reglas de negocio y despacho combinado de confitería.

## 💡 Atajos y Funciones de Demostración
* **Tecla `H` o botón "Mostrar Pistas":** Muestra todas las zonas clicables con un borde neón.
* **Clics libres:** Si se hace clic en cualquier zona no interactiva, los botones interactivos parpadean para guiar al usuario.
* **Menú lateral de Casos:** Permite navegar entre el *Camino Feliz* y los flujos alternativos.
* **Selector directo:** Desplegable superior para saltar a cualquier pantalla específica.
